# DBA802 — AI, Data Analytics & Strategic Decision Intelligence

Research repository for **DBA802: Data Analytics and Strategic Decision Intelligence**.

## About This Repository

This repository supports a research paper applying artificial intelligence and predictive analytics to a strategic decision-intelligence problem. The current study — **"Artificial Intelligence for Cyber Defense: A Predictive Analytics and Risk-Based Decision Framework Using UNSW-NB15"** — evaluates four machine learning classifiers (Logistic Regression, Random Forest, XGBoost, MLP) on network intrusion detection, then converts model output into a risk-tiered, decision-ready recommendation layer rather than stopping at classification accuracy.

The goal of the work is to demonstrate, end to end, how AI-driven predictive analytics can be turned into **explainable, actionable strategic decision intelligence** — not just a model with a reported accuracy number.

## Where the Work Lives

`main` holds only this overview. The full experimental pipeline — source code, prepared dataset, reproducibility scripts, results, and the research paper — lives on:

**[`feature/cybersecurity-ai-pipeline`](../../tree/feature/cybersecurity-ai-pipeline)**

That branch contains:

- `src/` — data loading, model training, evaluation, explainability, and decision-intelligence logic
- `run_experiment.py` — the primary experiment (train/test split across four classifiers)
- `run_rigor_experiment.py` — 5-fold cross-validation, paired significance testing, and hyperparameter search
- `data/prepared/` — the UNSW-NB15 subset used for training and evaluation
- `docs/Research_Paper_IEEE.pdf` — the final research paper (IEEE format)
- `outputs/` — generated metrics, figures, and predictions (regenerated by running the scripts; not stored in git)

## Reproducing the Results

```bash
git clone https://github.com/Nithish4603/DBA802.git
cd DBA802
git checkout feature/cybersecurity-ai-pipeline

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python run_experiment.py --quick   # fast smoke test
python run_experiment.py           # full experiment
python run_rigor_experiment.py     # cross-validation, significance testing, hyperparameter search
```

## Research Focus Areas

This repository sits within the broader DBA802 theme of **Data Analytics and Strategic Decision Intelligence**, applied here to one of the critical and emerging technology areas: **AI-enabled cybersecurity**. The framework — predictive model → explainability → risk scoring → recommended action — is intended to generalize beyond this dataset to other domains where a classification or prediction task needs to end in a decision, not just a score.
